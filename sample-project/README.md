# Sample E-Commerce REST API

This is a sample student project used to verify and demonstrate the **AI Project Mentor** application.

## Technologies Used
- Node.js & Express.js
- MongoDB & Mongoose
- JSON Web Tokens (JWT) for authentication
- Bcryptjs for password hashing
- CORS & Dotenv

## Modules
- **Authentication**: User registration, login, and JWT issuance
- **Users**: User model with encrypted credentials
- **Products**: Product catalog browsing and admin product creation

## Missing Potential Modules
- Shopping Cart
- Orders & Checkout
- Payment Gateway Integration (Stripe / Razorpay)
- Notifications (Email / SMS)
